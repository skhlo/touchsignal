Compact instrument layout

Stable agents, truthful thermals, and a reserved center.

  • Letters stand in for final agent logos. Each logo and status sign uses the same 27-pixel visual box.
  • One persistent Codex slot plus four Herdr slots keeps five-button geometry stable.

  • The power profile uses explicit choices and waits for source verification.
  • The center is intentionally empty and belongs to future context.
